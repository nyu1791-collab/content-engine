AIコーディングアシスタントやエージェントを利用する際、セッションが終了するたびに前提知識や過去の作業経緯がリセットされてしまう課題があります。

「claude-mem」は、エージェントが実行した内容を記録・圧縮し、次回のセッションへ関連するコンテキスト（文脈情報）として受け渡すためのオープンソースソフトウェア（OSS）です。本記事では、公式リポジトリの公開情報に基づいて概要や導入方法を整理します。

## claude-memで何ができるか

claude-memは、セッションをまたいでエージェントの文脈を保持（パーシステントコンテキスト）する仕組みを提供します。

公式ドキュメントによると、セッション中におけるエージェントのツール利用状況を自動的に記録（キャプチャ）し、AIを用いて意味的な要約（セマンティックサマリー）を生成します。そして、将来のセッションが開始された際に関連するコンテキストを自動で注入することで、セッションが終了または再接続された後でもプロジェクトに関する知識の継続性を維持します。

Claude Code向けに構築されているほか、OpenClaw、Codex、Gemini、Hermes、Copilot、OpenCodeなど複数のエージェント環境に対応していると案内されています。

## 主な特徴

リポジトリで公開されている主な仕様と特徴は以下のとおりです。

- **幅広いエージェントへの対応**: Claude Codeをはじめとする各種エージェントツールで利用可能
- **オープンソースライセンス**: Apache 2.0ライセンスで公開
- **実行環境**: Node.js（v20.0.0以上）が必要
- **選べるバックエンドプロバイダー**: ホスト型の「claude-mem observer」のほか、自身のOpenRouterキー、Geminiキー、またはAnthropicプランを選択可能

## インストールとセットアップ手順

公式READMEに記載されているセットアップ手順は次のとおりです。

### 基本インストール

ターミナルから以下の単一コマンドを実行します。

```bash
npx claude-mem install
```

インストーラーの実行後、ブラウザでメール宛の認証リンク（マジックリンク・クレジットカード不要）によるサインインが求められます。サインインを行うとアカウント用メモリキーが発行され、「claude-mem observer」の30日間無料トライアルが利用可能になります。無料期間終了後は、サブスクリプションに登録しない限り自動的にユーザー自身のAnthropicプランへフォールバックします。

サインイン後に、claude-mem observer、自身のOpenRouterキー、Geminiキー、Anthropicプランの中から使用するプロバイダーを選択します。

### サインインをスキップする場合

ブラウザサインインを行わずにセットアップする場合は、以下の方法が用意されています。

- 明示的に `--provider` フラグを付与してコマンドを実行する
- 環境変数 `CLAUDE_MEM_ONLINE_OPTIN=false` を設定する
- CI環境や非対話（non-interactive）環境で実行する

### Grok Bot向けのインストール

READMEにはGrok Bot向けのコマンドも明記されています。

```bash
npx claude-mem install --ide grok-bot
```

Grok Bot環境ではホストフックが存在しないためチャットログファイルを監視する仕組みとなっており、デフォルトではホスト型メモリである「CMEM Pro」が指定されます。ローカル監視に切り替える場合は `--provider host` を明示的に指定します。

## どんな人に向いているか

- Claude CodeなどのCLI系AIツールで開発作業を頻繁に行う方
- セッションが切れるたびに過去の修正内容や前提条件をAIへ再説明する手間を省きたい方
- プロジェクトの文脈を複数の外部キー（OpenRouterやGeminiなど）または独自プランと連携させて管理したい方

## 導入前の注意点

- **Node.jsのバージョン要件**: Node.js 20.0.0以上が動作環境として必須です。古いバージョンを使用している場合は事前のアップデートが必要です。
- **無料トライアル後の挙動**: 公式オブザーバーの30日無料トライアル終了後は、設定を継続しない限り自身のAnthropicプランにフォールバックされるため、API利用料金の発生状況には留意してください。
- **細かな設定や最新仕様**: ツールの更新頻度が高いため、詳細な環境変数やオプションの最新挙動については必ず[公式リポジトリ](https://github.com/thedotmack/claude-mem)で確認してください。

## まとめ

claude-memは、AIコーディングアシスタントの課題である「セッション終了に伴うコンテキストの喪失」を解消するためのOSSです。手軽なnpxコマンドでセットアップでき、多様なプロバイダー設定に対応しています。Claude Code等のエージェントを日々の開発業務で活用している方は、導入を検討してみてはいかがでしょうか。
