AIコーディングエージェントを使ってWebサイトやUIコンポーネントを生成する際、「どこかで見たような紫と青のグラデーション」「フォントがすべてInter」「カードの中にカードが並ぶ不自然なレイアウト」といった、いわゆる「AI特有のありきたりなデザイン（AI slop）」が出力されてしまうケースがあります。

こうした課題を解決するために公開されたオープンソースソフトウェア（OSS）が**Impeccable**（インペッカブル）です。本記事では、公式リポジトリの公開情報に基づき、Impeccableの機能や特徴、基本的な使い方、導入時の注意点を分かりやすく解説します。

## Impeccableとは？何ができるツールか

Impeccableは、公式ドキュメントで「コーディングエージェントのためのデザイン語彙（The design vocabulary for your coding agent）」と定義されているツールです。AIに対して「もっといい感じにして（Make it pop）」といった曖昧な指示を出すのではなく、体系化されたデザイン用コマンドを使って具体的な指示を与えることができます。

Claude Code、Cursor、GitHub Copilot、Codex CLIなど、幅広いAIコーディングツールに対応しており、既存のUIコンポーネントの改善やレビュー、品質チェックを効率的に行う仕組みを提供します。

## Impeccableの主な特徴

### 1. 62の決定論的ルールで品質低下を検知
Impeccableには、AIが生成しがちな不自然なデザインや品質問題を検知する**62のルール**が組み込まれています。狭すぎる余白（パディング）や見出しレベルのスキップなどを機械的に検出します。大規模言語モデル（LLM）のAPIを介さずに判定を行うため、APIキーは不要で動作します。

### 2. 目的別に用意された24種類のコマンド
Impeccableには、デザインの方向性調整からレビュー、仕上げまでをカバーする24個のコマンドが定義されています（うち1つは非推奨）。

- **調整（Steer）**:
  - `bolder`: 安全無難なデザインをより大胆にする
  - `quieter`: 主張が強すぎる要素を落ち着かせる
  - `distill`: 不要な要素を削ぎ落とす
  - `colorize`: 無機質な画面に色を加える
  - `typeset`: フォントや文字階層、サイズを整える
  - `layout`: 余白やリズムを修正する
  - `animate`: アニメーションや操作フィードバックを追加する
  - `delight`: 個性や遊び心を加える
  - `overdrive`: シェーダーやスクロール連動演出などを適用する
- **レビュー（Review）**:
  - `critique`: ユーザビリティの評価基準に沿ったスコア付きレビュー
  - `audit`: アクセシビリティ、パフォーマンス、レスポンシブ対応などをP0（最重要）〜P3で判定
- **仕上げ（Finish）**:
  - `polish`: リリース前の最終調整
  - `harden`: エラー表示、多言語化（i18n）、オーバーフローなどの例外処理を強化
  - `clarify`: 分かりにくい文言を改善
  - `adapt`: 各種画面サイズやデバイスへの最適化
  - `optimize`: 読み込みやレンダリングのパフォーマンス改善
  - `onboard`: 初回利用フローや空データ表示（Empty state）の設計
- **その他**: ブラウザ上で直接調整する`live`、UXを事前に計画する`shape`、コンポーネント抽出を行う`extract`などが用意されています。

### 3. ブラウザ上で変更を試せる「Liveモード」
`/impeccable live`を実行すると、ローカルの開発サーバー（Vite、Next.js、SvelteKit、Astro、Nuxt、プレーンHTMLに対応）上に操作用オーバーレイが表示されます。ブラウザ内で要素を選択し、バリエーションを切り替えて試したうえで、確定したコードをソースファイルに直接反映させることが可能です。

## Impeccableの使い方

### インストールと初期化
プロジェクトのルートディレクトリで以下のコマンドを実行してインストールします。

```bash
npx impeccable install
```

エージェントツールを再読み込みした後、エージェント環境内で初期化コマンドを実行します。

```bash
/impeccable init
```
※Codex CLIの場合は `$impeccable init` を使用します。

このコマンドを実行すると、コードベースの読み込みが行われ、製品の目的や制約をまとめた `PRODUCT.md` が生成されます。また、`/impeccable document` を実行することで、既存のデザインシステムを `DESIGN.md` に記録し、一貫性を保った指示が可能になります。

### 指示の出し方
改善したい対象（コンポーネントやセクション）を絞り込んで指示を出すことが推奨されています。

```text
/impeccable critique the pricing cards
/impeccable bolder the pricing cards
/impeccable polish settings
```

ページ全体を漠然と指定するよりも、特定のセクションに絞ってコマンドを適用する方が精度の高い結果を得られます。

## どんな人に向いているか

- **AIツールでフロントエンドを開発している人**: CursorやClaude CodeでUIを実装しているものの、デザインの質や手直しに時間を取られている開発者に向いています。
- **デザインの言語化が苦手なエンジニア**: 「なんとなくダサい」「もっと目立たせたい」といった曖昧な要望を、`bolder` や `typeset` などの明確なコマンドに変換して指示したい場合に適しています。
- **品質基準を揃えたいチーム**: アクセシビリティや余白の崩れを自動でチェックしたいプロジェクトに役立ちます。

## 導入時の注意点

- **新規作成よりも既存UIの反復改善に強みがある**: 公式ドキュメントにも記載されている通り、Impeccableは既存のコンポーネントやページに対してイテレーション（反復改善）を行う用途で最も強みを発揮します。
- **Liveモードの実行権限**: Liveモードはローカル開発環境での利用を前提としています。変更内容の適用時にはシェル環境の権限が利用される場合があるため、見知らぬリポジトリでの実行や本番環境への導入には注意が必要です。

## まとめ

Impeccableは、AIによるUI開発で生じがちな「画一的で質の低いデザイン」を改善し、的確な指示と客観的な品質チェックを可能にするツールです。日頃からコーディングエージェントを使ってWeb制作を行っている方は、開発フローに導入してみてはいかがでしょうか。詳細な仕様や最新のアップデートは、公式リポジトリおよびドキュメント（impeccable.style/docs）をご確認ください。
