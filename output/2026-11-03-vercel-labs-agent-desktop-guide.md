## agent-desktopとは？何ができるツールか

「agent-desktop」は、Vercel Labsが公開したAIエージェント向けのCLI（コマンドラインツール）およびC言語ライブラリです。AIエージェントがデスクトップ上の各種アプリケーションを認識し、クリックや文字入力などの操作を実行するために設計されています。

最大の特徴は、画面の画像認識（ピクセルマッチング）ではなく、OSが持つ「アクセシビリティツリー（視覚補助などのためにアプリのボタンや入力欄などのUI構造を管理する仕組み）」を読み取って操作を行う点です。

AIエージェントはデスクトップの状態をJSON形式のスナップショットとして取得し、各要素に割り振られた「ref（参照ID）」を指定してアクションを起こします。画像認識に頼らないため、操作対象の特定を構造データとして扱えるのが強みです。

## 主な特徴

### 1. 要素ごとに一意の参照ID（ref）を付与
画面の状態を取得（`snapshot`）すると、操作可能な要素ごとに `@s8f3k2p9:e8` のようなrefが付与されたJSONデータが出力されます。エージェントはこのrefを指定してクリックやテキスト入力を行い、再びスナップショットを取得して結果を確認するループを作ります。

画面のUIが更新されると古いrefは失効（`STALE_REF`エラー）し、再スナップショットを促す安全設計になっています。

### 2. デフォルトでヘッドレス（前面化・マウス移動なし）
refを対象とした操作はOSのアクセシビリティAPIを通じて行われるため、デフォルトではマウスカーソルを動かしたり、対象ウィンドウを無理に前面（フォーカス）に持ってきたりしません。バックグラウンドに近い形で動作します。なお、物理的な入力シミュレーションが必要な場合は、グローバルフラグの `--headed` を指定して実行できます。

### 3. AIエージェントと連携しやすいJSONインターフェース
すべてのコマンド実行結果は、成否を示す `ok` フィールド、実行結果の `data`、またはエラー詳細を含む `error` のJSONエンベロープ（定型構造）で標準出力されます。エラー時には、リトライが可能かどうかを示す安全判定（`disposition.retry`）や対処の提案（`suggestion`）も返却されます。

また、自身の中にドキュメントを保持しており、エージェント向け指示プロンプト（`AGENTS.md` など）に設定することで、エージェント自身が操作手順やプラットフォーム固有の仕様を読み取って自律的に動く仕組みも備えています。

### 4. 豊富な組み込みコマンド群
ツールには合計60種類のコマンドが用意されています（うち4つのキー・マウス押し続け系コマンドは制御デーモンの実装まで待機中となっており、実質56コマンドが即座に利用可能）。

- **観察系**: `snapshot`, `find`, `get`, `is`, `screenshot`, `list-surfaces`
- **refへの操作**: `click`, `type`, `set-value`, `clear`, `focus`, `scroll` など
- **マウス・キーボード直接操作**: `press`, `hover`, `drag`, `mouse-move` など
- **ウィンドウ・アプリ管理**: `launch`, `close-app`, `list-apps`, `list-windows`, `focus-window` など
- **その他**: クリップボード操作、通知取得・解除、セッション管理など

## インストールと基本的な使い方

### インストール方法
Node.js環境（npm、Bun、Yarn、pnpm）を使ってグローバルインストールが可能です。x64およびARM64向けのネイティブバイナリが含まれています。

```bash
npm install -g agent-desktop
agent-desktop version
```

JavaScript環境を介さずに単体バイナリとして使いたい場合は、GitHubのReleasesページからOSに合ったアーカイブを取得して利用することも可能です。※HomebrewやScoopの公式カタログへの登録は申請中と案内されています。

### 基本操作の流れ
基本は「状態取得（観察） → refを指定して操作 → 再度状態取得（確認）」の3ステップです。macOSのFinderを例にした場合、以下のように実行します。

```bash
# 1. 操作対象アプリのインタラクティブな要素一覧をスナップショットで取得
agent-desktop snapshot --app Finder -i

# 2. 出力されたJSONに含まれる「ref_id」を指定してクリック
agent-desktop click @s8f3k2p9:e8

# 3. 再度スナップショットを取得し、操作結果を確認
agent-desktop snapshot --app Finder -i
```

スナップショットを実行すると、以下のようなJSONデータが返されます。

```json
{
  "version": "2.6",
  "ok": true,
  "command": "snapshot",
  "data": {
    "app": "Finder",
    "window": { "id": "w-204749", "title": "Downloads" },
    "snapshot_id": "s8f3k2p9",
    "ref_count": 59,
    "complete": true,
    "tree": {
      "role": "window",
      "name": "Downloads",
      "children": [
        { "role": "treeitem", "name": "Documents", "ref_id": "@s8f3k2p9:e8", "available_actions": ["Click"] }
      ]
    }
  }
}
```

## プラットフォームごとの対応状況と必要な権限

macOS、Windows、Linux（X11 / Wayland）の各環境に対応していますが、OSごとに必要な準備が異なります。

- **macOS**: アクセシビリティの利用権限付与が必要です（`agent-desktop permissions --guide` で確認可能）。
- **Windows**: 実行ターミナルと同じ整合性レベルのアプリであれば、追加の権限付与なしで動作します。
- **Linux**: グラフィカルセッションと `at-spi2-core` が必要です。Wayland環境でのクリップボード操作には `wl-clipboard` が必要となります。

| 機能 | macOS | Windows | Linux |
|---|:---:|:---:|:---:|
| アクセシビリティツリー | 対応 | 対応 | 対応 (AT-SPI) |
| クリック / 文字入力 | 対応 | 対応 | AT-SPI / X11・GNOME keys |
| マウス操作 | 対応 | 対応 | X11、`--headed` 時 |
| スクリーンショット | 対応 | 対応 | X11ウィンドウ / Waylandポータル |
| クリップボード操作 | 対応 | 対応 | 対応（Waylandは要 `wl-clipboard`） |

## どんな人・用途に向いているか

- **デスクトップアプリの自動化スクリプトを組みたい開発者**: 画像認識によるマウスクリック自動化で座標ズレに悩まされていたケースにおいて、アクセシビリティツリーベースの安定した操作環境を構築できます。
- **ローカル環境で自律動作するAIエージェントを作りたい人**: 出力がすべて構造化JSONであり、エラーハンドリング指針も含まれているため、LLM（大規模言語モデル）のファンクションコーリングやツール利用と親和性が高いです。

## 利用時の注意点

- **機密情報の取り扱い**: スナップショットのJSON、クリップボードの内容、スクリーンショット、コマンドログなどには、デスクトップ画面に表示されているプライベートな情報が含まれる可能性があります。公開ログや外部サーバへの不用意なアップロードを行わないよう注意喚起されています。
- **PowerShellでの記法**: WindowsのPowerShellでは、`@` から始まる文字列が特殊な演算子（スプラッティング）と解釈されるため、refを指定する際は `'@s8f3k2p9:e8'` のようにシングルクォートで囲む必要があります。
- **複数ウィンドウ存在時の挙動**: 対象アプリに複数のウィンドウが存在する場合、`AMBIGUOUS_TARGET` エラーになります。エラー情報内の候補リストから対象のウィンドウIDを確認し、`--window-id` を明示して実行する必要があります。

## まとめ

Vercel Labsの「agent-desktop」は、画面の画像マッチングに頼ることなく、OSのアクセシビリティ機能を活用してデスクトップアプリを確実に操作できる開発者向けCLIです。JSONによる明確なやり取りや堅牢なエラーハンドリングなど、AIエージェントの組み込みを強く意識した設計が特徴です。PC上の業務自動化やエージェント開発を検証したい方は、リポジトリやnpmパッケージをチェックしてみてください。
